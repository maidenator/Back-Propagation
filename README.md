# CS345 Backpropagation Neural Network

A from-scratch C# implementation of a backpropagation neural network, built on the 4-input / 5-hidden / 3-output architecture from Dr. James McCaffrey's CS345 reference program and extended with the two exercises from its "WHAT TO DO" section: **cross-entropy loss** and **L2 weight decay**.

Only the .NET base class library is used. No NuGet packages, no ML.NET, no TorchSharp. Every forward pass, gradient, and weight update is written out explicitly with `double[]` and `double[][]`.

## Architecture

```
Inputs (4 features)      Hidden Layer (5 nodes, tanh)      Outputs (3 classes, softmax)
     [ x0 ]  ---------------->  ( h0 )  ---------------->  [ y0 ]
     [ x1 ]  ---------------->  ( h1 )  ---------------->  [ y1 ]
     [ x2 ]  ---------------->  ( h2 )  ---------------->  [ y2 ]
     [ x3 ]  ---------------->  ( h3 )
                                ( h4 )
```

43 trainable parameters: 20 input-to-hidden weights, 5 hidden biases, 15 hidden-to-output weights, 3 output biases.

Training data is generated by a seeded teacher network (1,000 synthetic items, 1-of-N one-hot targets, 80/20 train/test split) and is therefore reproducible.

## Quick start

Requires the .NET 8 SDK or newer.

```bash
git clone https://github.com/maidenator/Back-Propagation.git
cd Back-Propagation
dotnet restore BackPropagation.sln
dotnet build BackPropagation.sln --configuration Release
dotnet run --project src/BackPropagation.csproj
```

The default run trains all three configurations on the same dataset and prints a comparison table.

## Results

1,000 synthetic items (seed 1), 80/20 split, 1,000 epochs, learning rate 0.05, momentum 0.01, weight decay 0.001:

| Configuration | Loss | Weight Norm | Train Acc | Test Acc |
|---|---|---|---|---|
| 1. Baseline (MSE, no decay) | MSE | 15.83 | 99.75% | 100.00% |
| 2. Cross-entropy (no decay) | Cross-entropy | 45.20 | 95.00% | 93.50% |
| 3. Cross-entropy + weight decay | Cross-entropy | 3.32 | 90.62% | 87.00% |

The weight norm is the clearest evidence that the regularizer works: adding L2 weight decay contracts it from 45.20 to 3.32.

Cross-entropy removes the softmax derivative factor `y(1-y)` from the output signal, so the gradient stays strong even when the network is confidently wrong. Mean squared error keeps that factor and saturates.

Values are deterministic for a given runtime version; the .NET random number generator differs between major versions, so other runtimes can shift the last digit or two.

## Options

| Flag | Description |
|---|---|
| `--compare`, `-a` | Train all three configurations and print the comparison table (default) |
| `--menu`, `-m` | Interactive terminal menu |
| `--synthetic`, `-s` | Single 4-5-3 benchmark using mean squared error |
| `--cross-entropy`, `-ce` | Single benchmark using cross-entropy loss |
| `--weight-decay`, `-wd` | Single benchmark using L2 weight decay (lambda = 0.001) |
| `--logic`, `-l` | 4-input boolean logic gate experiment (train until fit) |
| `--optimize`, `-o` | Hidden neuron count optimization sweep |
| `--trace`, `-t` | Step-by-step arithmetic trace for one sample |
| `--visualize`, `-v` | ASCII network topology and parameter count |
| `--gui`, `-g` | Windows Forms dashboard (Windows only) |
| `--epochs`, `-e N` | Override the number of training epochs (default 1000) |

## Project structure

```
src/
├── Program.cs            # CLI entry point and interactive menu
├── Core/                 # engine: MatrixNeuralNet, activations, OO neuron variant
├── Data/                 # synthetic dataset, logic gate dataset
├── Experiments/          # single benchmarks and the 3-way comparison runner
├── SelfDoc/              # math tracer, ASCII visualizer, markdown reporter
└── GUI/                  # Windows Forms dashboard (Windows only)
```

Generated reports are written to `reports/` at runtime and are gitignored.
