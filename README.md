# CS345 Backpropagation Neural Network

### A primitive, self-documenting C# implementation with Cross-Entropy Loss, L2 Weight Decay, a terminal interface, and a Windows Forms GUI

This is a from-scratch educational implementation of a **backpropagation artificial neural network** in **C# / .NET 8**. It follows the 4-input, 5-hidden, 3-output architecture from Dr. James McCaffrey's CS345 reference program and extends it with the two exercises from the article's **“WHAT TO DO”** section: **cross-entropy loss** and **L2 weight decay**.

The engine uses only the .NET base class library. There are no NuGet packages, no ML.NET, no TorchSharp, and no third-party linear-algebra libraries. Every forward pass, activation, gradient, and weight update is written out explicitly with `double[]` and `double[][]`.

---

## Features

### Core CS345 model

- **4 → 5 → 3 topology** with **43 trainable parameters** (35 weights + 8 biases).
- **1,000 synthetic data items** generated by a seeded teacher network, with 1-of-N one-hot targets and an 80/20 train/test split.
- **Tanh hidden activation** and **Softmax output activation**.
- **Online stochastic gradient descent with momentum** (`η = 0.05`, `α = 0.01` by default).
- Winner-takes-all classification accuracy on both training and test partitions.

### Extensions from “WHAT TO DO”

1. **Cross-entropy loss**
   $$E = -\frac{1}{N}\sum_{i=1}^{N}\sum_{k=1}^{K} t_{ik}\ln(y_{ik})$$
   With a Softmax output layer, the output signal simplifies to:
   $$\delta_k = t_k - y_k$$
   The derivative factor is cancelled analytically, which avoids Softmax saturation.

2. **L2 weight decay / regularization**
   $$E_{\text{total}} = E + \frac{1}{2}\lambda\sum w^2$$
   The regularization term is applied to weight updates, but not to biases:
   $$\Delta w = \eta\left(\text{grad} - \lambda w\right) + \alpha\,\Delta w_{\text{prev}}$$

### Interfaces and self-documentation

- **Windows Forms GUI** (`src/GUI/MainForm.cs`) for generating data, configuring hyperparameters, training with live progress, predicting on custom inputs, and exporting a Markdown report. The GUI is compiled only on Windows.
- **Interactive terminal menu** that works on Linux, macOS, and Windows.
- **Step-by-step mathematical tracer** showing actual forward-pass and backward-pass arithmetic for one sample.
- **ASCII topology visualizer** with parameter counts.
- **Automatic Markdown reports** containing architecture, hyperparameters, accuracy, and serialized weights.
- **Primitive object-oriented variant** (`NeuralNet`, `INeuron`, `HNeuron`, `ONeuron`) used by the 4-input logic-gate experiment and hidden-neuron optimizer.

## Mathematical Specification

### Forward pass

For hidden node $j$:

$$z_j^{(h)} = \sum_{i=0}^{3} x_i w_{ij}^{(ih)} + b_j^{(h)}, \qquad h_j = \tanh\left(z_j^{(h)}\right) = \frac{e^{z_j} - e^{-z_j}}{e^{z_j} + e^{-z_j}}$$

For output node $k$:

$$z_k^{(o)} = \sum_{j=0}^{4} h_j w_{jk}^{(ho)} + b_k^{(o)}, \qquad y_k = \operatorname{Softmax}\left(z_k^{(o)}\right) = \frac{e^{z_k^{(o)}}}{\sum_{m=0}^{2} e^{z_m^{(o)}}}$$

### Backward pass

The hidden-layer error signal uses the Tanh derivative:

$$\delta_j = \left(1 - h_j^2\right)\sum_{k=0}^{2}\delta_k w_{jk}^{(ho)}$$

The output signal depends on the selected loss:

- **Mean squared error (reference CS345 form):**
  $$\delta_k = (t_k - y_k)\,y_k\,(1 - y_k)$$
- **Cross-entropy with Softmax:**
  $$\delta_k = t_k - y_k$$

> The MSE form above follows the reference implementation. A fully general Softmax Jacobian would also include cross-class terms; this project intentionally mirrors the article's formulation.

### Weight and bias updates

Input-to-hidden weights:

$$\Delta w_{ij}^{(ih)} = \eta\left(\delta_j x_i - \lambda w_{ij}^{(ih)}\right) + \alpha\,\Delta w_{ij}^{(ih,\text{prev})}$$

Hidden-to-output weights:

$$\Delta w_{jk}^{(ho)} = \eta\left(\delta_k h_j - \lambda w_{jk}^{(ho)}\right) + \alpha\,\Delta w_{jk}^{(ho,\text{prev})}$$

Biases are updated without weight decay:

$$\Delta b = \eta\,\delta + \alpha\,\Delta b_{\text{prev}}$$

The loss values printed during training are the data losses. The L2 penalty is applied to the weight updates; it is not added to the reported metric.

The project file chooses its target framework at build time:

- **Windows:** `net8.0-windows`, with `UseWindowsForms` enabled.
- **Linux / macOS:** `net8.0`, so the console application builds and runs directly.

This is why `dotnet run` works without `--framework` on every platform.

## Requirements

- **.NET 8 SDK** or newer (8.x recommended).
- On Windows, the .NET desktop development components are recommended for the WinForms GUI.
- On Linux/macOS, no GUI dependencies are needed.

Check your SDK:

```bash
dotnet --version
```

## Build

From the repository root:

```bash
dotnet restore BackPropagation.sln
dotnet build BackPropagation.sln --configuration Release
```

A clean build should produce **0 warnings and 0 errors**.

### Continuous integration

The workflow in [`.github/workflows/ci.yml`](.github/workflows/ci.yml) builds the solution on both **Ubuntu** and **Windows**, then runs the topology, math-trace, and synthetic-benchmark smoke tests on Linux. It runs on pushes and pull requests targeting `main`.

---

## Run

### Linux / macOS

Launch the interactive terminal menu:

```bash
dotnet run --project src/BackPropagation.csproj
```

Build and run a specific benchmark:

```bash
dotnet run --project src/BackPropagation.csproj --configuration Release -- --synthetic
```

The `--` separates .NET CLI arguments from arguments passed to the program.

### Windows

Open `BackPropagation.sln` in Visual Studio and press **F5**, or run:

```bash
dotnet run --project src/BackPropagation.csproj
```

With no arguments on Windows, the **Windows Forms GUI** launches automatically. To use the terminal interface on Windows:

```bash
dotnet run --project src/BackPropagation.csproj -- --cli
```

### Command-line options

| Option | Alias | Description |
|---|---|---|
| `--synthetic` | `-s` | Standard CS345 4-5-3 benchmark with MSE |
| `--cross-entropy` | `-ce` | CS345 benchmark using cross-entropy loss |
| `--weight-decay` | `-wd` | CS345 benchmark using L2 weight decay (`λ = 0.001`) |
| `--logic` | `-l` | 4-input logic-gate train-until-fit experiment |
| `--optimize` | `-o` | Hidden-neuron count optimization sweep |
| `--trace` | `-t` | Step-by-step arithmetic trace for one sample |
| `--visualize` | `-v` | ASCII network topology and parameter count |
| `--gui` | `-g` | Launch the Windows Forms GUI (Windows only) |
| `--cli` | `-c` | Force the terminal menu on Windows |
| `--help` | `-h` | Show help |

Examples:

```bash
# Cross-entropy extension
dotnet run --project src/BackPropagation.csproj -- --cross-entropy

# L2 weight-decay extension
dotnet run --project src/BackPropagation.csproj -- --weight-decay

# Single-sample mathematical trace
dotnet run --project src/BackPropagation.csproj -- --trace

# ASCII topology diagram
dotnet run --project src/BackPropagation.csproj -- --visualize

# Logic-gate experiment
dotnet run --project src/BackPropagation.csproj -- --logic
```

## Representative Results

Using the seeded 1,000-row dataset, the default 800/200 split, and 1,000 epochs:

| Mode | Loss | Weight decay | Train accuracy | Test accuracy |
|---|---|---|---:|---:|
| Standard CS345 | MSE | 0.0 | 100.00% | 100.00% |
| Cross-entropy | Cross-entropy | 0.0 | 97.25% | 96.50% |
| Weight decay | MSE | 0.001 | 96.75% | 93.00% |

These values are representative and can vary slightly across runtimes because floating-point behavior and random-number generation may differ. The synthetic dataset and the teacher network are seeded, so repeated runs on the same platform are deterministic.

A prediction on the article's example input `(1.0, 2.0, 3.0, 4.0)` produces a “moderate” classification with high confidence.

## Generated Reports

Every benchmark writes a Markdown report to `reports/` relative to the current working directory:

- `reports/cs345_run_<timestamp>.md` for the synthetic benchmark.
- `reports/run_<timestamp>.md` for the logic-gate experiment.

Report filenames include milliseconds and a collision suffix so multiple runs never overwrite one another. The `reports/` directory is created automatically and is **gitignored**.

## Source Materials and Academic Note

The original CS345 article PDF, the CS345 reference C# program, and the cloned third-party reference repository are **not included** in this repository. They are kept locally under `materials/` and `references/`, both of which are gitignored.

Keeping them out of version control:

- avoids publishing copyrighted course material or third-party code,
- avoids committing a nested Git repository,
- avoids checking in reference build artifacts and IDE files.

The published source is the original implementation in `src/`; the local materials were used only as study references.
